# Simple Line Editor

## About the Project

Simple Line Editor is a terminal-based text editor developed using the C programming language.

The project allows users to create and manage a text document using simple commands.

## Features

- Insert a new line
- Delete a line
- Display the document
- Save the document to a file
- Load a document from a file
- Search for a word or phrase
- Help command
- Exit the editor

## Technologies Used

- C Programming
- GCC Compiler
- Visual Studio Code
- File Handling
- Arrays and Strings

## How to Run

Compile the program using:

```text
gcc main.c -o editor
